## 概览

爱先蜂(axf 取自"爱先蜂"拼音首字母)是 1802 期 Django 课程的课设项目,模仿"爱鲜蜂"模式实现的
**O2O 闪送超市电商 Demo**。四个主要页面:主页(轮播/导航/必买/便利店)、闪送超市(商品分类与筛选)、
购物车(增删改查与下单)、我的(登录注册/收货地址/订单/评价/文件上传)。

它是典型的"课程项目即完整产品雏形"样本:功能边界清楚,业务流完整,自带移动端 H5 适配。

**当前状态**:已归档,仅保留源码作为历史学习参考。

## 核心功能

| 模块 | 能力 |
| --- | --- |
| 🏠 主页 | 轮播图(Swiper)、导航、必买推荐、便利店入口 |
| 🏪 闪送超市 | 商品分类展示与筛选 |
| 🛒 购物车 | 商品增删改查、数量联动、下单 |
| 👤 我的 | 登录 / 注册、收货地址管理、订单列表、商品评价、头像文件上传 |
| 🔐 认证拦截 | 登录状态判断与未登录拦截跳转 |
| 🗃️ 数据初始化 | 附带商品数据插入脚本,开箱即可填充商品库 |

## 技术栈

| 层 | 选型 |
| --- | --- |
| 后端 | `Python 3` · `Django 1.11.4`(MTV 架构、ORM、模板、会话) |
| 数据 | `SQLite`(Django 默认) |
| 前端 | `jQuery 3.1.1` · `Bootstrap 3.x` · `Swiper` |
| 模板 | Django 模板系统 + 模板继承 |

## 架构亮点

- **MTV 模式的完整落地**:Models、Views(基于函数)、Templates 三层清晰,是 Django 课程知识点的集中演练
- **自定义用户模型**:继承 `AbstractUser` 扩展 `icon` 字段,避免了后期迁移用户表的痛苦
- **抽象基类 `Common` 抽离公共字段**:轮播图、导航、必买、便利店等首页模块复用同一抽象模型,体会 ORM 继承映射
- **一对多 / 多对多关系**:商品类别与商品、用户与购物车、用户与订单,关系建模完整
- **登录拦截与会话管理**:购物车等模块的登录状态校验与拦截装饰器
- **模板继承体系**:`{% raw %}`{% block %}` / `{% url %}` / `{% load static %}`{% endraw %}` 的工程化使用

## 学习收获

课设项目最大的价值是"把框架的每个部件都用一遍":模板继承、{% raw %}`{% url %}`{% endraw %} 反向解析、静态资源加载、
Django ORM 的关系操作,都在一个真实业务里串起来。移动端 H5 适配部分完整实践了 viewport、
rem 布局与底部固定 Tab Bar 的经典做法。Django 1.11.4 发布于 2017 年、2020 年已停止官方支持,
重跑需自行降级环境;`SECRET_KEY` 明文硬编码属于课设常见做法,不可用于生产。
