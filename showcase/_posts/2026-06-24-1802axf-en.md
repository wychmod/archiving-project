## Overview

AiXianFeng (axf, from the pinyin initials of the Chinese name) is a course project from a Django class,
an **O2O flash-delivery supermarket demo** modeled after "AiXianFeng". It has four main pages: home
(carousel / navigation / must-buy / convenience store), the flash market (product category and filtering),
the cart (CRUD plus checkout), and profile (login, registration, addresses, orders, reviews, file upload).

It is a classic "course project as a product skeleton": clear feature boundaries, a complete business flow,
and mobile H5 adaptation built in.

**Status**: Archived — source kept for reference.

## Tech Stack

| Layer | Choice |

| Backend | `Python` · `Django 1.11.4` |
| Data | `SQLite` (Django default) |

| Templates | Django template system with template inheritance |
| Adaptation | HTML5 / CSS3 · mobile H5 (viewport / rem / bottom tab bar) |

## Architecture Highlights

- **A full pass over MTV**: models, function-based views, and templates — a concentrated exercise of every Django lesson topic
- **A custom user model**: extends `AbstractUser` with an `icon` field, avoiding painful migrations later
- **An abstract `Common` base class**: carousel, navigation, must-buy, and convenience-store blocks reuse one abstraction
- **One-to-many and many-to-many relations**: product categories to products, users to carts, users to orders
- **Session handling and login guards**: cart and checkout routes check the login state

## What It Taught Me

The value of a course project is using every part of the framework at least once: template inheritance,
reverse URL resolution, static asset loading, and relational ORM operations, all wired into real business flows.
Django 1.11 has long been out of support, so re-running it needs a downgraded environment; the hard-coded
`SECRET_KEY` is the usual course-project habit and must not ship to production.
