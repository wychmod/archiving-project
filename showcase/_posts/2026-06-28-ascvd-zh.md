## 概览

`ascvd`(**A**thero**s**clerotic **C**ardio**v**ascular **D**isease risk assessment)是一个面向
**心血管疾病风险评估、血脂亚组分分析、基因多态性解读**的临床辅助信息系统。系统为心血管内科医生、
临床检验技师、精准医学研究人员提供患者档案管理、多指标联合风险评估、报告生成、后台管理的一体化平台。

> ⚠️ 本系统为医疗辅助工具,所有诊断结论需经执业医师确认后方可作为临床决策依据。

**当前状态**:已归档(**已脱敏** + README 升级)——原仓库明文提交的 6 个凭证在导入时已统一替换为占位符。

## 核心功能

| 模块 | 能力 |
| --- | --- |
| 👤 患者档案 | `Apps/patient` 维护姓名/年龄/性别/联系方式/慢性病史,级联关联检验报告 |
| ❤️ ASCVD 风险评估 | `Apps/ascvd` 基于 TC/TG/HDL-C/LDL-C/non-HDL/Apo-A1/Apo-B/LP(a) 多指标联合分析,自动生成风险等级与诊断结论(`AscvdTesting` Model) |
| 🧪 血脂亚组分 | `Apps/blood_lipid_subfraction` 精细化血脂分型数据接入 |
| 🧬 基因多态性 | `Apps/gene_polymorphism` 基因位点录入与表型辅助判读 |
| 📋 报告元信息 | `Apps/report_information` 样本类型/条码号/样本号/样本状态四元组管理 |
| 🩺 医生工作台 | `Apps/user` 医生档案与权限隔离 |
| 📖 疾病字典 | `Apps/disease_dict` 慢性病字典维护(多选) |
| 🔄 诊断流程可视化 | 前端基于 `react-flow` 的多步骤决策流 |
| 🖼️ 报告图片导出 | `html2canvas` + `react-viewer` 的截图与回显 |
| ⚙️ 零代码后台 | `tyadmin-api-cli` 一键生成 Ant Design Pro 风格管理后台 |

## 技术栈

| 层 | 选型 |
| --- | --- |
| 后端 | `Python 3.8` · `Django 4.1` · `Django REST Framework 3.13`(Router / Serializer / Viewset) |
| 数据 | `MySQL 8` · `mysqlclient 2.1.1`(含 `SET default_storage_engine=INNODB` 兼容 hack) |
| 权限/过滤 | `django-guardian 2.4`(对象级权限) · `django-filter 22.1` · `django-simple-captcha` |
| 前端 | `React 18.2` · `MobX 6`(装饰器 Store) · `Ant Design 4.23` · `React Flow 11` · `axios` |
| 构建 | `react-app-rewired` + `customize-cra`(绕过 eject 定制 CRA) |
| 后台 | `TyAdmin 0.8`(零代码生成 Ant Design Pro 风格后台) |
| 部署 | `uWSGI`(socket 模式,4 进程 × 2 线程)+ `Nginx` + Docker(端口 8101-8111 → 主机 6101-6111) |

## 架构亮点

- **7 个业务 App 的领域切分**:患者档案 / 风险评估 / 血脂亚组分 / 基因多态性 / 疾病字典 / 报告元信息 / 医生工作台,核心 ascvd 应用经 10 次 migration 演进
- **多指标联合风险评估**:基于 TC/TG/HDL-C/LDL-C/non-HDL/Apo-A1/Apo-B 等指标生成风险等级与诊断结论
- **诊断流程可视化**:基于 React Flow 的多步骤决策流编辑器
- **报告图片化**:`html2canvas` DOM 截图 + `react-viewer` 浏览器内查看
- **零代码后台**:TyAdmin 基于 DRF Model 反射一键生成管理后台
- **多环境打包**:`dotenv-cli` 注入 `.env.dev` / `.env.prod` 双轨环境
- **企业级部署链路**:collectstatic + Nginx 静态直出、`MEDIA_ROOT` 媒体文件走 Django serve + Nginx `/media/`
