## 概览

`ascvd`(**A**thero**s**clerotic **C**ardio**v**ascular **D**isease risk assessment)是一个面向
**心血管疾病风险评估、血脂亚组分分析、基因多态性解读**的临床辅助信息系统。系统为心血管内科医生、
临床检验技师、精准医学研究人员提供患者档案管理、多指标联合风险评估、报告生成、后台管理的一体化平台。

> ⚠️ 本系统为医疗辅助工具,所有诊断结论需经执业医师确认后方可作为临床决策依据。

**当前状态**:已归档(**已脱敏** + README 升级)——原仓库明文提交的 6 个凭证在导入时已统一替换为占位符。

## 技术栈

| 层 | 选型 |
| --- | --- |
| 后端 | `Python 3.8` · `Django 4.1` · `Django REST Framework 3.13` |
| 数据 | `MySQL 8` · `mysqlclient` |
| 权限/过滤 | `django-guardian`(对象级权限) · `django-filter` · `django-simple-captcha` |
| 前端 | `React 18` · `MobX 6` · `Ant Design 4` · `React Flow 11` |
| 构建 | `react-app-rewired` + `customize-cra`(CRA 定制) |
| 后台 | `TyAdmin`(零代码生成 Ant Design Pro 风格后台) |
| 部署 | `uWSGI` + `Nginx` |

## 架构亮点

- **7 个业务 App 的领域切分**:患者档案 / 风险评估 / 血脂亚组分 / 基因多态性 / 疾病字典 / 报告元信息 / 医生工作台
- **多指标联合风险评估**:基于 TC/TG/HDL-C/LDL-C/non-HDL/Apo-A1/Apo-B/cardio 等指标生成风险等级与诊断结论
- **诊断流程可视化**:基于 React Flow 的多步骤决策流编辑器
- **报告图片化**:`html2canvas` DOM 截图 + `react-viewer` 浏览器内查看
- **零代码后台**:TyAdmin 基于 DRF Model 反射一键生成管理后台
- **多环境打包**:`dotenv-cli` 注入 `.env.dev` / `.env.prod` 双轨环境

这是归档序列中业务复杂度最高的项目:医疗领域的数据建模(指标 → 结论)、对象级权限、
流程可视化编辑、报告导出,以及企业级部署链路(uWSGI + Nginx + 静态资源直出)。
